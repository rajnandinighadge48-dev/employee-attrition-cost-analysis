# employee-attrition-cost-analysis
HR Analytics project analyzing employee attrition, salary, training cost and workforce insights using Excel, SQL, Python and Tableau.
# Employee Attrition & Cost Analysis

## 📌 Project Overview

An end-to-end HR Analytics project focused on understanding employee attrition, workforce patterns, salary trends, training investment, overtime impact, and employee-related costs.

The project demonstrates how HR data can be transformed into meaningful business insights using:

- Microsoft Excel
- MySQL / SQL
- Python
- Tableau Public

## 🎯 Business Objective

The objective is to identify:

- Overall employee attrition rate
- Departments with higher attrition
- Major reasons for employee turnover
- Relationship between overtime and attrition
- Salary patterns across employees
- Training investment
- Estimated employee-related cost
- High-risk departments requiring HR attention

## 🛠️ Tools & Technologies

| Tool | Purpose |
|------|---------|
| Excel | Data cleaning, calculations & HR analysis |
| SQL | Data querying & workforce analysis |
| Python | Data analysis & visualization |
| Tableau | Interactive HR dashboard |

## 📊 Key Metrics

- Total Employees: 15
- Total Attrition: 6
- Attrition Rate: 40%
- Average Monthly Salary: ₹53,066.67
- Total Training Cost: ₹544,000
- Calculated Total Loss: ₹30,602,000

## 🔍 Key Analysis Areas

### Department-wise Attrition
Analyzed employee count and attrition rate across IT, HR, Finance, Sales, Marketing and Operations.

### Attrition by Reason
Identified major employee exit reasons including:

- Workload
- Low Satisfaction
- Career Growth
- Better Opportunity

### Overtime vs Attrition
Compared attrition rates between employees working overtime and those who did not.

### Salary Analysis
Analyzed average, minimum and maximum salary and compared salary levels between employees who left and those who stayed.

## 📈 Dashboard

The Tableau dashboard provides a visual summary of:

- Department-wise Attrition Rate
- Attrition by Reason
- Average Salary by Department

## 🔄 Project Workflow

**Dataset → Excel → SQL → Python → Tableau → HR Insights**

## 💡 Business Insights

The analysis helps HR teams understand workforce turnover patterns and identify areas that may require further investigation.

The results can support data-driven discussions around:

- Employee retention
- Workload management
- Employee satisfaction
- Career development
- Compensation
- Workforce planning

## ⚠️ Project Limitation

This project uses a small sample dataset created for portfolio and learning purposes. The calculated loss metric represents the project's defined employee-cost calculation and should not be interpreted as a complete organizational replacement-cost model.

## 🚀 Future Improvements

Future versions could include:

- Larger real-world HR datasets
- Predictive attrition modeling
- Employee engagement analysis
- Machine learning
- Advanced Tableau dashboards
- Automated HR reporting
